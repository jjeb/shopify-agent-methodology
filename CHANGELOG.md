# Changelog

All notable changes to Shopify Agent Methodology are documented here.

The project follows [Semantic Versioning](https://semver.org/). The package is
versioned as one coordinated set of role skills; individual roles do not have
independent release versions.

## [Unreleased]

Changes for the next release will be recorded here.

## [0.3.0] - 2026-10-22

### Changed

- Renamed the canonical installable role from `shopify-data-engineer` to
  `shopify-data-integration-engineer`.
- Added a migration and compatibility guide for existing prompts and routing
  configuration.
- Kept ShopifyQL, reporting, and aggregate analytics separate from operational
  data integration; no duplicate legacy alias is installed.

## [0.2.0] - 2026-10-21

### Added

- Canonical capability-maturity tags for the six core roles.
- Researched Shopify platform-surface coverage with explicit ownership,
  evidence, and future-specialist boundaries.
- Skill-local maturity sections and synchronized methodology reference copies.

## [0.1.0] - 2026-10-20

### Added

- Six installable Shopify role skills for coordination, architecture,
  development, operational data, store operations, and review.
- Delivery-first guardrails, role contracts, lifecycle guidance, handoff
  records, coordination guidance, and evaluation scenarios.
- Installation, initialization, authentication, and development-store safety
  guidance.
