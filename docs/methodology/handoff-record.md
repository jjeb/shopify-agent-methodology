# Shopify Handoff Record

Use this record when work moves between roles or when an agent stops with work
remaining. Keep it concise, factual, and copyable into the next agent's
context.

```text
Request:
Current state:
Target store/project/environment:
Decision or work completed:
Evidence:
Files, commands, or links:
Required permissions/scopes:
Known risks and unresolved questions:
Recommended next role:
Explicit authorization still required:
```

## Evidence rules

- Cite the command, file, query, preview, or readback that supports a claim.
- Separate observed results from recommendations and inferences.
- State when a check was not run, a response was partial, or a live result was
  not verified.
- Never include passwords, access tokens, session cookies, or unnecessary
  customer data.
- A handoff is incomplete when the next role cannot identify the target,
  current state, required permission, unresolved risk, or next action.
