# Documentation History

This directory contains completed implementation plans and design
specifications retained as historical records. They preserve the reasoning,
scope, and verification context for work already delivered.

These files are not active plans, current requirements, or roadmap items. The
active roadmap is maintained in [GitHub Issues](https://github.com/jjeb/shopify-agent-methodology/issues)
and the [Shopify Agent Methodology Roadmap project](https://github.com/users/jjeb/projects/1).
Use the linked issue and pull request state as the current source for deferred
work; do not infer current priorities from an archived plan or specification.

Historical documents may contain paths that were current when they were
written. Relocation-only link updates preserve their original content while
keeping references navigable from this directory.
